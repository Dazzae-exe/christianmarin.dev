# AGENTS.md - Guia de los agentes

Este archivo es el punto de entrada para cualquier agente que trabaje en este repositorio. NO es una biblia de reglas: es un mapa. Lee solo lo que necesites cuando lo necesites (divulgación progresiva).

## Reglas claras

- TypeScript estrictamente.
- Buenas practicas de React 19.
- No comentarios en el codigo. 
- Un solo feature a la vez. No mezcles tareas, procura completar una tras una.
- No declares una prueba done sin pruebas en verde.

## Antes de empezar (obligatoriamente)

1. Leer el progreso en `docs/tareas/progreso` para entender que quedo en la ultima sesion.
2. Leer las tareas `docs/tareas/tareas.json` elige una tarea en estado `pending`. No trabajes mas de una a la vez. 

## Como elegir una tarea

```markdown
1. Abre `docs/tareas/tareas.json`
2. Filtra las tareas por estado `pending`
3. Escoge la de menor id
4. Cambia el status a `in_progress` y guarda
5. Anota en `docs/tareas/progreso/PROGRESO.md` fecha de inicio, feature y plan breve.
```
